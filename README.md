# CoraLEAN

**CoraLEAN** is a methodology-first project to design and validate a conversational improvement coach for Lean Healthcare / Quality Improvement.

The initial product hypothesis is **not** a standalone SaaS platform. The first version will run primarily inside a ChatGPT Project using Project instructions, AGENTS.md, reusable Skills where available, Chat/Voice/Work, structured project state and a visual cockpit. PROMueve Extremadura — beginning with the Mérida Rheumatology–Pharmacy project — is the first real-world laboratory.

The long-term architecture may add a shared backend, a cockpit, MCP integration and eventually a standalone platform. Those are hypotheses to validate, not commitments.

## Current status

**Phase 0 — method and product discovery.**

The repository is intentionally documentation-first. Do not begin building a full platform merely because a technology is available.

## Core idea

> CoraLEAN should teach a person to think well enough to lead a real improvement project, not merely teach them which Lean tool to click.

The AI is the cognitive partner. CoraLEAN owns the method, project state, governance and user experience.

## Pilot

The first live test is the PROMueve Extremadura Mérida project (Rheumatology + Pharmacy), with the first working session planned for **26 October 2026**.

## Repository

This repository is intentionally independent from PROMueve. PROMueve is a laboratory and source of real-world learning; CoraLEAN is the reusable product/methodology.
