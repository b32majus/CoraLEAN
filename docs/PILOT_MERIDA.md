# Pilot — PROMueve Extremadura · Mérida

## Purpose

Use a real PROMueve improvement project as the first laboratory for CoraLEAN.

## Project

**PROMueve Extremadura — Mérida**
- Rheumatology + Pharmacy
- Kickoff: 30 September 2026
- First working session: **26 October 2026**

The kickoff introduced the project and how the team will work. The month before the first working session is the opportunity to prepare and test CoraLEAN.

## Why this pilot is valuable

It gives CoraLEAN:

- a real project;
- a real professional user;
- a real improvement problem;
- a real deadline;
- an expert facilitator (Silvia);
- an opportunity to test transfer of capability;
- a controlled environment to discover methodological and UX friction.

## Pilot hypothesis

CoraLEAN should help Silvia prepare and conduct the project while also helping the local pharmacist progressively learn to lead similar work independently.

## What we want to test

### Method

- Are the reasoning areas, decision foci and derived navigation moment useful?
- Does Coraline know what to ask?
- Does it prevent premature solutions?
- Does it identify missing evidence?
- Does it know when not to move on?

### Interaction

- Is Chat useful for reasoning?
- Is Voice useful for an inexperienced user?
- Is Work useful for consolidation and artefacts?
- Are the human-language commands intuitive?

### State

- Does PROJECT_STATE remain coherent?
- Can a person understand the project without reading the entire chat?
- What information is repeatedly lost?

### Cockpit

- Does a visual overview materially improve orientation?
- Which information needs to be visible at a glance?
- Which interactions should open a conversation?

### Pedagogy

- Does Guided mode teach without slowing the project?
- Does Partner mode feel like a trusted peer?
- Can the pharmacist become progressively more autonomous?

## Success criterion

The pilot is not primarily successful if the team likes the tool.

**Execution guardrail (23 Oct):** until runtime is validated, Silvia operates any CoraLEAN assistance and the local lead answers first. Baseline, interventions by Silvia vs AI, critical reasoning errors and follow-up **without the tool** should be recorded separately. This is exploratory evidence, not verified effectiveness.

It is successful if CoraLEAN contributes to **capability transfer**:

> the local project lead can progressively perform more of the project work with less direct intervention from Silvia, while methodological quality remains acceptable.
