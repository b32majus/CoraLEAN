# CoraLEAN Product Vision

## Problem

Many healthcare professionals are interested in improving processes but do not feel able to lead a structured improvement project independently.

The bottleneck is usually not knowing that tools such as VSM, Fishbone, 5 Whys or PDSA exist.

The bottleneck is knowing:

- what to ask first;
- how to define the real problem;
- who needs to be involved;
- what is evidence versus assumption;
- when to observe rather than solve;
- what needs to be measured;
- when the project is ready to move forward;
- how to run the next meeting;
- how to turn messy discussion into a coherent project state;
- how to learn from tests rather than defend solutions.

## Product thesis

CoraLEAN should behave like an **improvement coach / trusted partner**, not like a Lean encyclopaedia.

The central experience is:

> "Tell me what is happening. I will help you think through what we need to know, what to do next and whether we are ready to move forward."

## Why conversational AI is useful

Conversational AI is good at:

- asking adaptive questions;
- synthesising messy notes;
- challenging assumptions;
- generating alternative hypotheses;
- drafting artefacts;
- explaining concepts;
- preparing meetings;
- transforming qualitative information into structured state.

But generic chat has weaknesses:

- context can become opaque;
- state is difficult to visualise;
- the next step is not always explicit;
- decisions can disappear in conversation;
- the model can advance too quickly;
- methodological quality is not guaranteed.

CoraLEAN therefore adds **method + state + gates + cockpit** around the AI.

## Product layers

### 1. CoraLEAN Core

Reusable method and governance.

### 2. ChatGPT Project

The first runtime surface.

### 3. CoraLEAN Desk

A visual cockpit showing where the project is, what is open and what comes next.

### 4. Shared backend

A future source of truth when shared, real-time access becomes necessary.

### 5. MCP

A future bridge allowing AI conversations to read/write structured project state.

### 6. Standalone platform

Only if real usage demonstrates that the above layers are insufficient.

## Distribution models

### Resource model

CoraLEAN is distributed as a Starter Kit.

The user owns/creates their own ChatGPT Project and, if needed, their own infrastructure.

### Service model

CoraLEAN is provided as a managed service.

Silvia/CoraLEAN provisions the backend and cockpit, and can access the project state to provide coaching/support.

This second model is strategically important because the service is not only software: it includes **human improvement coaching when needed**.

## Strategic relationship with PROMueve

PROMueve is the first laboratory.

It provides:

- real improvement projects;
- real facilitation challenges;
- real methodological edge cases;
- real user behaviour;
- real friction findings.

CoraLEAN should not become a PROMueve subsystem.

## Strategic relationship with SanitarIA

SanitarIA can later become the public education/distribution layer:

- explain how CoraLEAN was built;
- teach people to create their own AI-supported improvement workspace;
- share anonymised/synthetic examples;
- publish learnings from the build;
- recruit pilot users;
- eventually offer training/service packages.

## North-star outcome

> Increase the capability and autonomy of professionals to lead good improvement projects without requiring an expert improvement coach to be physically present at every step.
